# Travel México · My México. My Way. (English Edition)

Standalone web application for **My México. My Way.**, allowing travelers to design bespoke journeys across Baja California and the Mexican Caribbean.

## Features
- **Curated Experience Creator**: 17 themed interest filters in an accessible 3-column layout.
- **22 Sourced Destinations**: High-resolution stock photography and editorial guidance for all 22 destinations across Baja California and the Mexican Caribbean.
- **Dynamic Itinerary Simulation**: Multi-day trip planning with customized pace and real activity scheduling.
- **Client-Side PDF Export**: One-click professional PDF guide generation.

## Development

```bash
npm install
npm run dev
```
